# Указания для интеграции

Используй [INTEGRATION.md](INTEGRATION.md) как контракт подключения WebHID к существующему предпросмотру. Сохраняй поддержку чтения 24C08 и используемые стандарты SFF-8472. Операции сохранения в вышестоящем приложении должны оставаться явными.

Запускай `node test-webhid.mjs` после правок. На GitHub Pages приложение находится под префиксом репозитория, поэтому используй относительные ссылки на файлы страницы. Не включай в репозиторий дампы реальных устройств, учётные данные и материалы локальной настройки.
