# CH347 Web I²C Reader

Браузерное чтение EEPROM 24C08 через **CH347T в USB HID-режиме** (`1A86:55DC`). CH347 подключается к компьютеру с браузером. Страница обращается к нему через WebHID и сохраняет результат в BIN. Данные EEPROM обрабатываются в браузере.

[Открыть приложение](https://gimran.github.io/CH347_WEB_I2C_READER/) · [Интеграция](INTEGRATION.md) · [Указания для ИИ](AGENTS.md)

## Использование

1. Откройте приложение в Chrome или Edge. Освободите CH347 в других утилитах.
2. Нажмите **«Подключить CH347»** и выберите **HID To UART+SPI+I2C**.
3. Приложите щуп и нажмите **«Прочитать»**. По умолчанию считываются 1024 байта со смещения `0x000`; скорость — 400 кГц. Уберите щуп после сообщения об успешном чтении.
4. Вкладка **EEPROM** показывает HEX-дамп. Вкладка **Парсер** показывает A0h SFP Info и **Thresholds** из A2h. Чтобы получить обе области, прочитайте не менее 512 байт со смещения `0x000`.
5. **«Сохранить BIN»** скачивает дамп как `DD-MM-YYYY_Vendor_PN.bin`. Если Vendor или PN отсутствуют, используются `UnknownVendor` и `UnknownPN`.

**Авточтение** выключено по умолчанию. После включения первая попытка запускается сразу, следующие идут с настраиваемой задержкой после завершения предыдущей. Начальный интервал — 0,5 секунды. При NACK остаётся последний успешный дамп. Доступны 20, 100, 400, 750 кГц и экспериментальный номинальный режим 1 МГц.

## Локальный запуск

Установите Node.js, клонируйте репозиторий и запустите `node webhid/serve.mjs` или `start-eeprom-webhid.cmd` в Windows. Откройте [http://localhost:5173/](http://localhost:5173/). GitHub Pages предоставляет HTTPS для сетевого использования, а локальный HTTP работает через localhost. [WebHID в Chrome](https://developer.chrome.com/docs/capabilities/hid)

## Обмен с EEPROM

Модуль читает банки `0x50–0x53` блоками до 32 байт, без пересечения границ 256 байт. Команда задаёт указатель, выполняет повторный START и считывает данные. Чтение проверяет ACK и длину HID-ответа. Запись в EEPROM отсутствует. A0h и DDM разбираются по SFF-8472. [Спецификация SNIA](https://members.snia.org/document/dl/25916)
