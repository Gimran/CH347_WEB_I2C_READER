# Интеграция WebHID в веб-проект

Скопируйте [webhid/reader.mjs](webhid/reader.mjs) в исходники фронтенда и раздавайте его со своего сайта по HTTPS. Для локальной разработки подходит `http://localhost`. CH347 подключается к компьютеру пользователя. Браузер запрашивает доступ к устройству для origin приложения.

## Подключение к предпросмотру прошивки

Найдите обработчик штатного выбора BIN. Рядом добавьте действие **«Считать с программатора»**. Вызов `connectCh347` должен начинаться непосредственно в обработчике нажатия. Если предпросмотр принимает `File`, оберните считанный `Uint8Array` в файл и передайте его этому обработчику.

```js
import { connectCh347, readEeprom, eepromFilename } from "./reader.mjs";

readButton.addEventListener("click", async () => {
    readButton.disabled = true;
    let device;
    try {
        device = await connectCh347();
        const bytes = await readEeprom(device, { offset: 0, length: 1024, speedKhz: 400 });
        const file = new File([bytes], eepromFilename(bytes), { type: "application/octet-stream" });
        await previewFirmware(file); // Обработчик существующего предпросмотра
    } catch (error) {
        status.textContent = error.message;
    } finally {
        try {
            if (device?.opened) await device.close();
        } finally {
            readButton.disabled = false;
        }
    }
});
```

Для сценария SFP A0 + A2 запросите 512 байт со смещения `0x000`, если этот формат подтверждён для обработчика предпросмотра. Поддержку полного BIN 24C08 на 1024 байта проверьте отдельно. Сохранение в базе и назначение эталоном оставьте отдельными действиями пользователя.

## API

- `connectCh347(hid?, { speedKhz }?)` возвращает открытый `HIDDevice`. Без аргументов использует `navigator.hid` и 400 кГц.
- `readEeprom(device, { offset, length, speedKhz }?)` возвращает `Uint8Array`. Длина по умолчанию идёт до конца 24C08. NACK и транспортные ошибки отклоняют promise. При транспортной ошибке модуль может закрыть устройство.
- `parseSfpA0(bytes, offset?)` разбирает идентификацию SFP, поля производителя и контрольные суммы.
- `parseSfpDdm(bytes, offset?)` возвращает измерения, пороги и флаги SFF-8472. Проверяйте `state` и `ready`. Для полного разбора передавайте диапазон с A0h и A2h.
- `eepromFilename(bytes, offset?, date?)` формирует имя BIN из локальной даты, Vendor и PN.

При автоопросе планируйте следующую попытку после завершения текущей. Храните последний успешный дамп отдельно от состояния ошибки и отменяйте запланированную попытку при отключении автоопроса или устройства.

## Приёмка

1. Запустите `node test-webhid.mjs`. Проверьте, что результаты синтетических тестов успешны.
2. В Chrome или Edge проверьте выбор CH347, отказ в разрешении, отключение USB и повтор после NACK.
3. Дважды считайте 1024 байта с реального образца. Сравните длины и SHA-256, а при наличии эталона и его содержимое.
4. Передайте один и тот же образ через программатор и обычный выбор BIN. Сверьте предпросмотры при одинаковой раскладке. Убедитесь, что предпросмотр сам не создаёт запись в архиве.
5. Зафиксируйте браузер, адаптер, скорость, диапазон и результат сверки. Разделите результаты проверки на имитации и на оборудовании.
